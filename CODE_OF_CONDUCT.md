# Code of conduct

## The short version

Be decent. Argue with the work, not the person.

## Scope

This project does not accept pull requests
([`CONTRIBUTING.md`](CONTRIBUTING.md) explains why), so the only shared space
is the issue tracker and any discussion attached to it. That is what this
document governs, along with anything done in the project's name elsewhere.

## The standard

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

**Expected:**

- Say what is wrong and how you would know. "The MAE in the README does not
  reproduce, here is my run" is the most valuable thing anyone can file here.
- Accept that a maintainer may disagree, and that "measured, rejected, here is
  the number" is a complete answer.
- Assume the other person is competent and short of context, which is usually
  true.

**Not accepted:**

- Harassment, insults, or personal attacks, including on protected
  characteristics.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing anyone's private information without explicit permission.
- Sustained disruption — reopening a settled question without new evidence,
  or filing to make a point rather than to fix something.

## Enforcement

Report to vanshwar@gmail.com. Reports are read in confidence and the reporter's
identity is not shared with the person reported.

Responses escalate as the situation warrants: a private correction, an edited
or removed comment with a note saying why, a temporary block, or a permanent
one. There is one maintainer, so there is no appeals panel — which is a reason
to be careful with the tool, and it will be.

## A note on the model

This project predicts a number attached to a named, real person. Discussion of
its outputs — in issues, in write-ups, anywhere — should stay on the
model's accuracy and its limitations, not on the players. A prediction being
wrong is a fact about the model.
